# Changelog

## 2026-10-22
- Added `cuff_pressure.py`: reads the BMP280 on the Pico 2 W (MicroPython or CircuitPython, no libraries), zeroes to room air, prints cmH2O for Thonny's Plotter with 20/30 cmH2O target lines, warns above 80, saves each trial as CSV on the Pico. Auto-finds the sensor on any Grove I2C port.
- Added `Pico_BMP280_Setup.md`: wiring (Grove shield → BMP280), Thonny/firmware setup, how to run.
- Note: hardware is a Raspberry Pi Pico 2 W on a Grove shield, not a full Raspberry Pi, so the plan's "Pin 1/3/5/6" and "enable I2C" steps don't apply.
- `Pico_BMP280_Setup.md`: wiring table now lists the real wire colors from Imen's photo (VIN black, GND blue, SCK gray, SDI purple). Original kept in `_originals/`.
- `cuff_pressure.py`: added SPI mode so all 6 sensor wires are used, plugged onto the Grove shield's SPI0 header (VIN-3V3, GND-GND, SCK-SCK, SDI-TX, SDO-RX, CS-CS). Auto-detects SPI0 pins, still falls back to Grove I2C. Previous version in `_originals/cuff_pressure_v1_2026-10-22.py`.
- `Pico_BMP280_Setup.md`: wiring section rewritten for the SPI0 header with Imen's real wire colors.
- Not used: direct-to-Pico pin wiring (pins 36/38/6/7/3/9). The Pico sits in the shield, so its pins can't take jumper wires.
- `Pico_BMP280_Setup.md`: wiring table uses pin names only (no wire colors), per Imen.
- Final wiring (4 wires, I2C0): VIN→3V3 OUT, GND→GND, SCK→GP5, SDI→GP4. `cuff_pressure.py` now tries GP4/GP5 first (`OUR_WIRING`), then searches SPI0, every hardware I2C pin pair, and swapped SDA/SCL. Previous version in `_originals/cuff_pressure_v2_2026-10-22.py`. Setup sheet updated to match.
- Correction: the Grove shield does have free GP header holes beside the Pico, so direct GP-pin wiring works.
- `cuff_pressure.py`: added NeoPixel ring (Data In on GP22) and alarm speaker via Mono 2.5W amp (A+ on GP28). Ring: blue below 20 cmH2O, half lit green at 20, more lights fading to orange up to 30, all red flashing above 30. High alarm = fast two-tone; low alarm = slow low beep, armed only after the cuff first reaches 20. No libraries needed (uses built-in neopixel / neopixel_write). Runs fine if ring/speaker aren't wired. Previous version in `_originals/cuff_pressure_v3_2026-10-22.py`.
- `Pico_BMP280_Setup.md`: added section 1b with ring, amp and breadboard connections (pin names only).
